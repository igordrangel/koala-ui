Text Editor A rich text editor built with Tiptap. It supports headings, lists, tables, colors, images, and more through a customizable toolbar. Installation Use the Koala CLI to generate a new text editor component. Usage Bind the editor to a reactive form control to read and persist the generated HTML. Use extractTextEditorImageIds() on the control value to collect attached file ids.

Form value 

{{ editorValue() }}

HTML emitted by the form control. When images go through an API, temporary blob: URLs are stripped and only data-id is kept.

Attached image IDs 

{{ editorImageIds() | json }}

IDs extracted with extractTextEditorImageIds() from the form value. Use this list as assetsIds when saving to your backend.

Try it

Add an image from the toolbar, drag & drop, or paste. By default the file is embedded as base64. With a custom TextEditorFileService, the preview uses blob URLs while the persisted value keeps only the file id in data-id.

Images Image handling is internal to the editor. Implement TextEditorFileService with upload() and download() — typically extending HttpBase (kl install http-base) — and provide it on the page that uses the editor.

1. Upload a new image

When the user adds an image, the editor calls upload(folder, [file]) on your TextEditorFileService, receives the persisted id, then calls download(id) for preview. 

// inserted in the editor (preview only)
<img src="blob:..." data-id="file-id-from-api" class="editor-image" />

2. Resolve on load

When the form control receives saved HTML, the editor calls download(id) for each data-id before rendering and sets src with the blob URL. 

// persisted in your database
<img data-id="file-id-from-api" class="editor-image" />

// rendered in the editor after resolve()
<img src="blob:..." data-id="file-id-from-api" class="editor-image" />

3. Register the service

Provide your FileService on the page that uses the editor. When FileService is providedIn: 'root', use useExisting: 

providers: [
  {{ '{' }} provide: TextEditorFileService, useExisting: FileService {{ '}' }},
]

Pass the folder to the editor with [imageFolder].

4. Extract image IDs

Each image is persisted in the HTML as a data-id attribute on <img>. On save, read the form control value and call extractTextEditorImageIds(html) to collect every id into an array. 

const content = this.contentControl.value;
// '<p>Hello</p><img data-id="file-id-from-api" class="editor-image" />'

const assetsIds = extractTextEditorImageIds(content);
// ['file-id-from-api']

Alternatively, use viewChild(TextEditor) and read attachedImageIds() — a signal updated whenever the editor content changes.

5. Save the form

Send the normalized HTML and the extracted ids to your API. Temporary blob: URLs are already removed from the form value by the editor.

FileService

Extend HttpBase and implement TextEditorFileService with upload() and download(). Private helpers come first. The editor handles preview and HTML resolution internally.

Using the service in a form

Register TextEditorFileService on the component, pass imageFolder to the editor and use extractTextEditorImageIds() on the form value to build assetsIds before saving.

Reading image IDs with viewChild

Instead of parsing the HTML, read attachedImageIds() from a viewChild(TextEditor) reference. Both approaches return the same ids stored in data-id.
