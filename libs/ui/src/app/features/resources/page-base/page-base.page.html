PageBase PageBase is an abstraction resource for page components, providing breadcrumb navigation and a reload signal for child lists or tables. Installation Use the Koala CLI to add PageBase to your project. API

Signals

  • reload: Signal used to trigger a reload in child components.

Methods

  • reloadList(): Sets reload briefly so bound children can react.

Properties

  • breadcrumbs: Computed breadcrumb trail from the current ActivatedRoute.
Usage Use with the Breadcrumb component.
