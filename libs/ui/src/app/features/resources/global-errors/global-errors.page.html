Global Errors Global Errors provides automatic HTTP error feedback via toast notifications. A global interceptor captures failed requests and displays user-friendly messages. Installation Use the Koala CLI to add Global Errors to your project (includes Toast and app.config setup). API

Interceptor

  • FeedbackRequestInterceptor: Captures HTTP errors and delegates to HttpErrorFeedbackAlert.

Service

  • HttpErrorFeedbackAlert.tapError(): Shows warning (4xx), error (5xx), or info toasts.

Middleware

  • HttpErrorMiddleware.handleError(): Returns a sanitized message.
  • HttpErrorMiddleware.ignoreError(): Skips feedback for specific errors (customize after install).

Utility

  • sanitizeErrorMessage(): Extracts or maps messages from HttpErrorResponse.
Usage Requires the Toast component.
