HttpBase HttpBase is an abstraction resource for HTTP services, providing REST helpers, file downloads, and reactive data loading via rxResource. Installation Use the Koala CLI to add HttpBase to your project. API

Constructor

  • baseUrl: API base URL.
  • endpoint: Resource endpoint segment.

Protected methods

  • url(resourcePath?): Builds the full request URL.
  • get / post / put / patch / delete: HTTP verbs.
  • getFile: GET with arraybuffer response.
  • downloadFile: Triggers a browser file download.
  • resource(options?, resourcePath?): Returns an rxResource for reactive GET.
Usage Pair with Global Errors for automatic HTTP error feedback.
