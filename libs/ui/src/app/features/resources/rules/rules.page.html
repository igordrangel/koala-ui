Rules Rules provides route-level permission control. Routes registered with a rule are protected by RouteAccessGuard, which checks the logged user's permissions. Installation Rules is installed together with Auth. Use the Koala CLI to add authentication and route permissions. API

Types

  • RouteRule: Permission identifier (redefine in logged-user.ts).
  • RouteConfig: Route definition with optional rule, name, and iconClass.
  • RouteData: Data on protected routes (name, rule, iconClass, parent).

Function

  • routesRegistre(routes): Registers routes and applies RouteAccessGuard when rule is set.

Guard & Model

  • RouteAccessGuard: Redirects to login without token; checks hasPermission(rule).
  • LoggedUser.hasPermission(rule): Validates user rules. Undefined rule allows access.
Usage See also Auth and the Login block.
